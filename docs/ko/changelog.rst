변경 이력 (Change log)
=====================

.. currentmodule:: picozero
0.4.2 ... 0.4.5
---------------
+ ``I2cLcd`` 클래스 도입
+ 서보(Servo)를 위한 ``move_to_degree`` API 도입
+ AnalogOutput(ADC)을 위한 ``raw_value`` 속성 도입
+ 문서 정리 및 부수적인 수정

0.4.1 - 2022-12-22
------------------

+ ``pinout()`` 도입
+ ``DigitalInputDevice.when_deactivated`` 데코레이터 버그 수정
+ 문서 정리 및 부수적인 수정

0.4.0 - 2022-11-18
------------------

+ ``Servo`` 클래스 도입
+ 문서 수정

0.3.0 - 2022-08-12
------------------

+ ``Motor``, ``Robot``, ``DistanceSensor`` 클래스 도입
+ 다른 클래스들과 맞추기 위해 ``LED`` 팩토리의 ``use_pwm`` 파라미터를 ``pwm``으로 변경. **참고:** 이는 API가 변경되는 수정사항(Breaking change)입니다. 
+ ``pwm``을 사용하지 않을 때의 ``RGBLED`` 관련 이슈 해결
+ ``blink`` / ``pulse`` 비율이 ``0``일 때 트레이스백 에러가 발생하는 이슈 해결
+ 기타 사소한 버그 수정
+ 문서 업데이트

0.2.0 - 2022-06-29
------------------

+ Pico W 내장 LED 호환성 수정

0.1.1 - 2022-06-08
------------------

+ 테스트 중 발견된 사소한 버그 수정
+ 예외 메시지 소폭 개선
+ Speaker 및 PWMOutputDevice에 close 메서드 추가
+ 유닛 테스트 추가
+ RGBLED.color의 별칭으로 RGBLED.colour 추가

0.1.0 - 2022-04-08
------------------

+ 베타 릴리스
+ 문서 업데이트
+ 사소한 버그 수정 및 리팩토링

0.0.2 - 2022-03-31
------------------

+ 버그 수정 및 문서 업데이트

0.0.1 - 2022-03-21
------------------

+ 설치 프로세스 테스트를 위한 초기 알파 릴리스
